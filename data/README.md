# data/

No data is committed to this repository.

- Download and collection code lives in `src/rdp/` and is run through the `rdp` CLI or the `Makefile`. See [docs/collector.md](../docs/collector.md).
- Local data is written to `data/local/` by default (set `RDP_DATA_DIR` to change it). That folder is gitignored.
- Licence terms for each source are in [docs/data-sources.md](../docs/data-sources.md). Any small sample published later will follow them.
